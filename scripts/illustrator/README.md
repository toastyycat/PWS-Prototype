# A4-opdrachtkaarten

Open Illustrator en kies **Bestand → Scripts → Ander script…**. Selecteer `deelnemerskaarten.jsx` en kies daarna `public/deelnemers.csv`. Het script maakt een Illustrator-document met een A4-pagina per deelnemerscode (nu 100). Elke pagina bevat de 15 taken uit het CSV-rooster in volgorde. Sla het resultaat op als `.ai` of als PDF met alle artboards.

De boekingsdoelen en zoekopdrachten zijn overgenomen uit `src/shared/protocol.ts`. Als die bron verandert, werk de tekst en `scenarios` in het Illustrator-script ook bij voordat je opnieuw kaarten maakt.
